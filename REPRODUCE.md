# Reproducing this metadata edition

The source inventory represents the publisher's [sitemap](https://www.landesrecht-hamburg.de/sitemap1.xml) as observed on 12 November 2026. It counts each `<loc>` entry once, then classifies document identifiers beginning `jlr-`, `NJRE`, and `VVHA`. The 22,701 `jlr-` URLs are document entries, not verified distinct acts.

The attribution in `NOTICE.md` follows the portal's [imprint](https://www.landesrecht-hamburg.de/jportal/portal/page/fshelp.psml?cmsuri=%2Ftechnik%2Fde%2Fimpressum%2Fbshaimpressum.jsp) and the inspected gazette dataset's licence metadata. No legal text was copied into this edition, so there is no text reconstruction or text comparison to reproduce.
